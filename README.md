"# Time-zone" 
This is a Next.js e-commerce website for buying and selling products. 
It supports multiple themes, languages, and currency options.
## Features
- Multi-language support (English/Bangla)
- Multi-currency support (USD/BDT)
- Dark/Light theme toggle
- User authentication
- Shopping cart functionality
## Installation
1. Clone the repo: `git clone https://github.com/malaayeeka/Time-zone.git`
2. Install dependencies: `npm install` or `pnpm install`
3. Run dev server: `npm run dev`
## Usage
- Open `http://localhost:3000` in your browser
- Browse products, add to cart, toggle theme and language
